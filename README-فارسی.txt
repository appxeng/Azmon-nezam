آزمون‌یار نظام مهندسی — پروژه‌ی آماده‌ی تبدیل به APK

محتوای پوشه
- www/index.html  : خود برنامه (همه‌ی سوال‌ها و تصویرها داخل همین یک فایل است و به اینترنت نیاز ندارد، به‌جز فونت)
- www/manifest.json, sw.js, icon-*.png : برای نصب به‌صورت PWA
- capacitor.config.json, package.json : برای ساخت APK با Capacitor

راه ۱ (ساده‌ترین، بدون برنامه‌نویسی): سرویس‌های آنلاین تبدیل HTML به APK
  پوشه‌ی www را ZIP کنید (یا همین فایل ZIP را بدهید) و در سرویس‌هایی مثل AppsGeyser (گزینه‌ی HTML/Website) یا مشابه آن آپلود کنید.
  نکته: هر سرویس شرایط خودش را دارد؛ فایل APK را قبل از انتشار روی گوشی تست کنید.

راه ۲ (حرفه‌ای‌تر، با Android Studio و Capacitor)
  1) Node.js و Android Studio را نصب کنید.
  2) در پوشه‌ی پروژه:  npm install
  3) npx cap add android
  4) npx cap sync
  5) npx cap open android   (در Android Studio: Build > Build APK(s))

راه ۳ (PWA): پوشه‌ی www را روی یک هاست HTTPS بگذارید و از مرورگر گوشی «Add to Home screen» بزنید. برای APK می‌توانید از PWABuilder.com استفاده کنید.

محدودیت‌های مهم
- «ساخت سوال با هوش مصنوعی» و «ذخیره‌ی فایل از بانک» فقط داخل خود Claude کار می‌کند و در APK مستقل غیرفعال است (سوال‌های آماده و آزمون‌ها کار می‌کنند).
- لینک‌ها، سوال‌های واردشده و آمار پیشرفت داخل حافظه‌ی همان دستگاه ذخیره می‌شود.
- فونت وزیرمتن از اینترنت می‌آید؛ بدون اینترنت از فونت پیش‌فرض گوشی استفاده می‌شود.
- سوال‌ها هنوز با ویرایش فعلی کتاب‌ها تطبیق داده نشده‌اند و برچسب «تطبیق‌نشده» دارند.
